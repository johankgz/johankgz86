Le projet

Vous décrivez les pièces et ce qu'elles pilotent ; l'outil numérote les adresses de groupe comme dans vos projets ETS (même rangement, même numéro pour un circuit dans chaque sous-groupe) et produit le fichier XML à importer dans ETS.

Pièces

Un circuit sans nom prend le nom de la pièce. L'ordre des pièces donne l'ordre des numéros.

Systèmes Airzone

Chaque pièce chauffée choisit son système. Un système prend un groupe principal (8, 9, 10… jusqu'à 15), comme dans nos projets : « Multizone » pour un gainable à plusieurs zones (demandes, étages chaud et froid), « Monozone » pour une unité seule (filtre, ventilation, heures de fonctionnement). Le groupe 16 porte les modes généraux.

Avec l'adresse physique de chaque passerelle, l'outil sort la fiche de liaisons : les objets Airzone sont fixes (zone N : consigne = objet 23 + 16 × (N−1) + 4…), il ne reste qu'à les lier dans ETS.

Scénarios

Un par ligne : repas, TV, départ, coucher…

Le fichier pour ETS

Dans ETS : Adresses de groupe › Importer › choisir le fichier XML.

Aperçu

Analyser un fichier ETS

Un export XML des adresses de groupe : l'outil le résume et signale ce qui cloche (type de donnée manquant, commande et état qui ne portent pas le même nom au même numéro…). « Reprendre » en tire les pièces pour un nouveau projet.
